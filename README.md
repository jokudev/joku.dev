# joku.dev terminal

Interactive terminal-style portfolio built with Vite + TypeScript (no frontend framework).

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Commands

- `help`
- `clear`
- `whoami`
- `neofetch`
- `ls [path]` (`-la` supported)
- `cat [file]`
- `cd [path]`
- `pwd`
- `echo [text]` (`$SHELL`, `$HOME`)
- `date`
- `uptime`
- `history`
- `git log --oneline`
- `kubectl get achievements`
- `terraform plan`
- `ssh contact`
- `wget cv.pdf`
- `exit`

Easter eggs:

- `sudo ...`
- `rm -rf /`
- `make coffee`
- `hack` / `hackerman`
